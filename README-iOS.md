# Ежедневные уведомления на iPhone

В версии для iPhone используется системное локальное уведомление: оно повторяется каждый день в 10:00 по местному времени, даже когда приложение закрыто. При нажатии открывается раздел «День».

## Подготовка iOS-приложения

1. Установить Node.js 22 или новее и Xcode на Mac.
2. В этой папке выполнить `npm install`.
3. Выполнить `npm run cap:add:ios` один раз.
4. Выполнить `npm run cap:sync:ios`.
5. Выполнить `npm run cap:open:ios`, затем собрать и подписать приложение в Xcode.

При первом включении напоминания приложение запросит разрешение iPhone. Уведомление можно отключить в разделе «День».

Обычная страница GitHub Pages не может отправлять уведомления, когда закрыта. Файлы Capacitor нужны для сборки нативной версии.
